# 天空ドロップ・ロードスター（SKYDROP ROADSTER）

標高2600m、星の頂。崖の縁から**ドロップイン**して、**垂直の壁を駆け降りろ**。
重力で加速し続ける壁を噴射ブレーキで限界ギリギリに操り、ふもとのジャンプ台から空へ。
星空 → オーロラ氷壁 → 雲海 → 摩天楼 → キャニオン → 海岸線。
6つの崖を降りて、**海抜0mの夕陽の港**へ帰る 3D ダウンヒル・ドライブ。

「絶壁ロードスター（CLIFF ROADSTER）」の、登るゲームを裏返した姉妹作です（Three.js 描画・Web Audio 合成サウンド）。
設計の考え方は [JOURNEY.md](JOURNEY.md)（ジャーニーマップ）にまとめています。

## 遊び方
`index.html` をブラウザで開くだけ（ビルド不要・オフライン可。Three.js 同梱）。
ローカルで開く場合は簡単なサーバー経由がおすすめです：`npx http-server .`

| 操作 | キーボード | スマホ | ゲームパッド |
|---|---|---|---|
| 噴射（ジャンプ／上昇／**壁ではブレーキ**） | Space・↑・W | 右下「噴射」 | A |
| ハンドル | ← → / A D | 画面左側を左右スライド | 左スティック／十字 |
| ブースト | Shift・X | 「BOOST」 | RT・X |
| 一時停止 | P・Esc | II ボタン | Start |

### 崖の降り方
1. 「崖まで170m」の助走路で**AIRセル**を拾って、ブレーキ用のAIRを満タンに。
2. そのまま崖の縁へ進むと、タイヤが壁に吸い付いて**垂直に駆け降り始める**（ドロップイン）。
3. 壁では重力で**どんどん加速**する。**噴射を長押しでブレーキ**。
4. 速度計が赤い **REDLINE** ならスコア×2。限界速度を超えたままだと **GRIP** メーターが減り、ゼロで壁から剥がれる。
5. 「▲落石」は**背後から**来る。車線を変えるか、ブレーキを離して振り切る。「◆岩棚」は車線変更で、氷の上はブレーキが効かない。
6. ふもとの**ジャンプ台**から空へ。速いほど遠くへ飛ぶ。着地斜面の**K点**を越えよう。
7. 着地斜面の近くで**噴射**すると強く減速できる。着地点ガイドが緑になれば安全、早めの噴射でパーフェクト着地。
8. 走行中にジャンプして崖の縁を越えると**エア・ドロップイン**（ボーナス）。

### スター（各チャプター3つ）
★ 着地成功 ／ ★ ノーミス ／ ★ K点越え
ドロップを制覇すると、タイトルの**ジャーニーマップ**からそのチャプターに直接挑戦できます。

## 構成
```
index.html          画面・HUD（標高トラック・GRIP・REDLINE・飛距離・ジャーニーバナー）
css/style.css       UI
js/textures.js      Canvasによる手続きテクスチャ
js/models.js        車・障害物・景観・崖パーツの3Dモデル
js/world.js         チャプター・標高の計画・空・雲海・コース生成・崖とジャンプ台と着地斜面の形状
js/fx.js            パーティクル・着地ガイド・花火・天候
js/audio.js         サウンドエンジンとBGM（壁のレイヤー／ドロップ／ドロップイン・テイクオフ・K点の効果音）
js/game.js          物理（道路・壁・空中）・入力・カメラ・進行
js/vendor/          three.js r147（MIT）
JOURNEY.md          ジャーニーマップ設計書
```
